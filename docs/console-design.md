# 账号工作台界面规范：手机卡样板

## 参考与实现边界

2026-11-02实际阅读以下官方页面，均可访问：

- [Ant Design 数据列表](https://ant.design/docs/spec/data-list-cn/)：筛选、列表、分页、详情和上下文批量操作的层级。
- [ProTable 文档](https://pro-components.antdigital.dev/components/table/)与[基础示例](https://pro-components.antdigital.dev/components/table/api.html)：收起低频条件、选择反馈、工具栏和总数/页码。
- [字体](https://ant.design/docs/spec/font-cn/)、[布局](https://ant.design/docs/spec/layout-cn/)和[按钮](https://ant.design/components/button-cn/)：文字层级、适应电脑宽度、操作主次。

以下是本系统的设计选择，参考交互原则，不照搬品牌或引入组件库。继续使用原生 HTML、CSS、JS；本期仅手机卡启用，账号等页面后续分批验证。

## 视觉约定

令牌位于 `static/card-console.css`，使用 `--ui-*` 命名。主色沿用工作台绿色 `#087f68`；背景 `#f5f7fa`、表面白色、正文 `#1f2937`、辅助文字 `#667085`、边框 `#e4e7ec`。正文14/22，表格13/22，辅助12/20，页标题24/32，章节16/24；主要使用400/500/600字重。间距为4/8/12/16/24，输入与常规按钮36高，6/8圆角。保留“矩”和“账号工作台”标识，不加载外部字体、图片或运行依赖。

页面顺序：标题与新增 → 同步提示 → 当前筛选统计 → 筛选区 → 清单与分页 → 业务说明。每个操作区域最多一个突出主按钮；刷新、重置、详情为次级。已有权限仍决定可用操作，样式不替代权限。

## 手机卡交互约定

常用条件为办公室、号码、卡状态、运营商，输入即本地筛选，不增加网络请求。其他条件收进“更多筛选”，收起时显示生效数量。芯片显示所有已生效条件，支持逐项清除；重置保持办公室，清除办公室芯片则回到全部授权范围。五个快捷条件保留原筛选含义和计数。

清单8列，每页50张；突出号码、业务状态、位置与归属。长说明、完整关联账号、接码记录、归还日期、备注和导入原文在只读详情抽屉查看，使用已授权快照，不重复拉取全量数据。编辑和移卡仍进入原有流程。表格内部滚动、表头固定，主页面不因表格变宽而横向滚动。

未选中时只提供选本页入口；勾选后出现批量栏，明确已选数、本页数、筛选总数，可扩到全部筛选结果或取消。修改字段、预览确认、幂等与版本校验沿用原实现。

## 状态与安全含义

状态始终带文字，颜色仅辅助阅读：正常为绿色；欠费、停机、待注销为琥珀色；待确认、停用、已注销、空白和历史文字为中性。已注销是终态记录，不作为继续注销提醒。接码和归还独立显示，绝不由卡状态推导。核对条件已记录并不等于可以注销。

位置来源、实物确认与账号登录设备分别展示；归属按原 `office_ids`，关联按原注册手机号匹配。不得根据名称、尾号或原表位置猜关联。加载中、无资料、无匹配、请求失败分别显示；刷新失败保留旧资料并提供重试，不能显示成零结果。

## 验证与复用

用相同120张合成卡、相同关联账号、相同视口对比冻结4597858与候选。预览仅绑定本机地址、拒绝写请求，不连接业务库。验证筛选/重置/分页/只读详情/批量预览/状态提示与常用电脑尺寸；截图和测量另见本轮验收记录。本期不承诺生产提速，发布须有当次明确授权并另行确认服务器更新。后续复用必须另验相应业务状态、办公室权限和编辑草稿保护。
