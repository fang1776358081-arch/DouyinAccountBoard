# 办公室三主路径改版

## 决策来源与范围

依据“安装 grill-me skill”对话中最终的“确认目标一致”（2026-11-04）及本轮实施要求。以当前独立工作树为基线；原主目录办公室三的未提交修改不复制、不暂存、不覆盖。

按独立阶段交付：表格同步、账号中心、今日工作、公共导航与上下文。沿用原生 HTML/JavaScript/Python，不引入大型框架。员工办卡、姓名匹配、离职交接、平均分配、全办公室推广均不在本次范围内。

## 表格同步的成功标准

- 独立四阶段：上传同轮双表 → 预览更新与冲突 → 明确确认 → 批次回执。
- 安全新增与更新已有账号分开。仅真实抖音号原字符串精确匹配；不按名称、号码或手机序号猜身份。重复、矛盾或跨范围账号整行跳过。
- 来源空白不更新；只更新昵称、注册手机号、注册日期、明确映射的状态。资料登记电脑须唯一属于当前办公室且位置可用；不移动实际发布位置。
- 负责人、使用情况、违规状态、业务类型及门头保存在独立来源资料中，来源文字不覆盖人工备注。
- 不改账号身份、大小号关系、手机/卡关联、发布安排、发布历史、养号历史、其他办公室或待分配资料。
- 服务端试点开关默认关闭，只有总管理员可启停/写入；当前只开放办公室三。普通人员的可见范围仍按原权限。
- 预览绑定操作者、办公室、日期、文件摘要和资料版本，30分钟过期。固定请求编号；结果不明时只能核对或重试原请求。
- 持久批次记录来源、逐字段前后值、跳过/冲突及核对状态。回退必须反向预览，不覆盖后续修改，不删除已有依赖的新账号。
- 原文件及敏感列不持久化到浏览器、日志、Git或批次。

## 界面与交互标准

- 五个主任务入口：今日工作、账号中心、表格同步、资料与设备、管理工具。保留旧路由兼容，不删除低频业务能力。
- 电脑端优先、紧凑表格、50条账号分页、右侧详情、高频筛选与折叠高级条件。筛选防抖、条件标签、结果数及重置明确可用。
- 简单昵称/备注编辑显示保存状态、保留失败输入并支持受版本保护的短时撤销。状态/关系/批量流程保持明确确认。
- 编辑时暂停远端更新；正常浏览允许10–15秒检查间隔。同步保留筛选、页码、选中项及滚动上下文。
- 页面间只保留按用户/办公室隔离的安全界面状态；表格原文不存储，高风险预览离开前提醒。
- 日期仅发布相关页面显示；作品采集保留单账号、勾选批量、筛选结果及今日工作入口，未启用或无权限时禁用并说明原因，不开启采集；同步正常显示轻量状态，失败提供重试。

## 验证与停止条件

本地测试只用隔离合成SQLite/本机PostgreSQL和浏览器。覆盖精确身份、重复/冲突、空值、跨办隔离、预览失效、幂等、断网、回退后续修改、编辑保护及旧接口兼容。既有压缩与按需读取保持，不用重载全部业务数据修复界面。

发现跨办修改、身份错配、历史/关系变化、权限泄漏、结果不明或回退覆盖后续修改时停止写入。数据库迁移追加为独立可选扩展；不改已有迁移，不在应用启动执行生产DDL。

本轮开发不等于正式上线或试点通过。正式部署需按项目发布流程，且结构启用须先按受控流程备份及迁移；未取得真实冷暖/网络/办公室电脑测量时不宣称线上提速。试点通过仍需至少新增、更新、冲突核对、回执复查各一次及连续三个实际工作日无硬停止问题，再单办公室推广。

## 本机验收补充（2026-11-05）

- 恢复单账号详情、勾选账号、全部筛选结果和今日工作的作品采集入口；未启用及权限不足均禁用并解释，采集政策未改。历史数量、时间和错误继续展示。
- 真实 Chrome 合成环境发现并修复编辑框重绘触发自动保存、导致备注撤销失效的问题。增加同步焦点离开事件回归；昵称、换行备注撤销只提交各自字段，并拒绝覆盖后续修改。
- 修复异步预览完成后翻页按钮仍禁用的问题；预览与回执中已知来源字段显示中文。63 行预览真实验证第一页 50 行、第二页 13 行；重复、跨办公室冲突不可选。
- 本机真实操作覆盖办公室切换、分页选择、详情返回、筛选与重置、保存及撤销、双页面草稿保护和恢复增量同步、来源负责人筛选、双表更新／安全新增／重复导入／批次回执及回退。相同双表第二次预览为 0 新增、0 更新、0 字段变更；前导零抖音号原样保留。
- 普通员工只能查看授权办公室、账号编辑表单只读、表格同步写入被禁用。发布登记已验证未发→已发→未发及历史日期切换。没有使用正式资料。
- 本轮相关前端 216 项及发布 UI 契约通过；隔离 Python/HTTP/采集关闭/schema/package 13 项通过。既有本机 PostgreSQL 9 项仍为上一轮相同后端版本的结果，本轮未连接生产数据库或重跑生产迁移。
- 1366×768 验证无整页横向溢出、重复 ID 或控制台错误；1920×1080 视口覆盖未实际生效，不能宣称已验该尺寸。账号页首屏信息仍较多，需要滚动至列表；不把这次界面调整宣称为加载提速。
- 原生试点启停确认框本轮未再次操作；测试夹具仅对一次性合成库预先开启试点，未覆盖浏览器确认函数或放宽规则。正式冷暖网络、真实办公室电脑及连续三工作日试点仍待发布后验收。
- 候选仍未提交、推送或上线；生产数据、权限及采集开关未改，原主目录 12 个旧修改哈希不变。测试页面和夹具服务已关闭。
