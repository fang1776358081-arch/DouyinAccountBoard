# 账号资料页本机样板

## 范围

基于 `787c8b86cb89` 的独立工作树。仅调整 Go 内嵌网页的账号资料展示，沿用原生 JavaScript、Go API、授权、版本锁、请求回执与 WebSocket。没有新增框架、外部字体或运行时 CDN。

交互参考 [Baserow 网格](https://baserow.io/user-docs/guide-to-grid-view)，视觉参考 [Tabler](https://preview.tabler.io/)。新增样式与展示助手为本项目实现，不引入这两个平台的后端。

## 样板行为

- 昵称、完整抖音号、状态、登录手机及注册卡、发布位置、备注在同一张表格中对齐；点击完整抖音号打开原有详情抽屉。
- 昵称、状态和备注仍使用原单元格编辑：双击或键盘开启、Enter/失焦保存、Esc取消；备注用Ctrl+Enter保存。
- 工具栏可折叠筛选、调整可见字段及舒适/紧凑行距。身份列始终可见；当天发布默认收起，可在“显示字段”打开。
- 展示偏好仅保存在当前页面内存，不存业务资料；增量重绘时重新应用。有未结束草稿时阻止视图调整，避免编辑框失焦或被隐藏。
- 原办公室、日期、筛选、分页和批量选择口径保持。共用模板切到每日发布或其他模块时移除样板样式并恢复控件位置。
- “本机试用”标记仅在回环地址显示，正式网站不标记为本机或示例资料。

## 本机运行与验证

本轮使用 `go/.local/account-sheet-20261118-a2c0/` 下的全新合成夹具和回环 PostgreSQL，实际库名、可执行文件及测试账号配置由该目录的私有运行文件管理，不能提交。

- 样板入口：`http://127.0.0.1:8080/?page=accounts&office=go-east`。
- 原版对照：本轮测试进程监听 `127.0.0.1:8081`，使用同一份合成资料。
- 专项浏览器验证：该私有目录下的 `browser-proof.cjs`，覆盖搜索、分页、字段显隐、密度、草稿、保存、详情、批量、权限与双会话更新。
- Go 最小包验证：在 `go/` 执行 `go test -mod=readonly ./internal/webassets ./internal/realtime`。
- 本地重新编译后需刷新网页；Go将静态资源内嵌在可执行文件中。

这些测试结果只描述本机合成环境，不代表正式站性能。Go内嵌资源需要重新构建二进制后部署，推送源码不等于正式版本已经更新。业务关联规则和生产数据不在本轮改动范围。
